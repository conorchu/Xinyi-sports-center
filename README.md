# 🏸 信義運動中心 AR 導引

使用 MindAR + Three.js 製作的 WebAR 導引原型。

使用者不需要安裝 App，
只需要透過手機瀏覽器開啟網站並允許相機權限，
即可透過場景圖片進行 AR 辨識與箭頭導引。

---

## 🛠 使用技術

- HTML
- CSS
- JavaScript
- Three.js
- MindAR
- Netlify
- GitHub
